# Daily Journal Tracker

A clean, minimal daily tracker and journal — built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies, no setup required.

## Features

- **Mood tracking** — log how you're feeling each day with one tap
- **Habit tracking** — check off six daily habits (water, exercise, sleep, meditation, reading, screen-free time)
- **Task list** — add, complete, and remove tasks for the day
- **Health log** — track steps, water intake, sleep hours, and weight
- **Daily notes** — free-form journal entry for reflections and thoughts
- **Streak counter** — see how many consecutive days you've logged
- **Dark / Light mode** — toggle between themes; preference is saved automatically
- **Date navigation** — browse back and forward through past entries
- **Persistent storage** — all entries are saved in your browser's localStorage

## Getting Started

### Option 1 — Open locally
Download `index.html` and open it directly in any browser. No installation needed.

### Option 2 — Host on GitHub Pages
1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set the branch to `main` and click **Save**
4. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Usage

- Use the **← →** arrows to navigate between days
- Click a mood button to log how you're feeling
- Click any habit tile to toggle it on/off
- Click **+ Add task** to add tasks; check them off as you complete them
- Fill in the health fields and notes, then hit **Save entry**
- The **☀️ / 🌙** button in the header switches between light and dark mode

## Data & Privacy

All your journal data is stored **locally in your browser** using `localStorage`. Nothing is sent to any server. Clearing your browser data will erase your entries, so export or back up important entries manually if needed.
